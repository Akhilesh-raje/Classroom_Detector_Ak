# SmartClass AI — Real Classroom Video Analysis

This folder contains everything needed to run the AI analysis on the real classroom video. It is self-contained — just install dependencies and run.

## Quick Start (3 steps)

### Step 1 — Make sure Python packages are installed

Open a terminal in the **parent `classroom/` folder** (one level up) and run:

```bash
pip install -r backend/requirements.txt
```

> Only needed once. Skip if already done.

### Step 2 — Run the analyzer

**Option A — Double-click (Windows):**
Just double-click `run.bat` in this folder.

**Option B — From terminal:**
```bash
cd "C:\Users\rajea\Documents\classroom\classrom video of wit"
python analyze.py
```

**Option C — Use a different video:**
```bash
python analyze.py "C:\path\to\your\video.mp4"
```

### Step 3 — Wait for model loading

The first time you run it, AI models load from disk (~15–50 seconds).
You will see:
```
Loading AI models (one-time ~15-50s)...
Ready in 22.3s
```
After that, the preview window opens and analysis starts immediately.

## What Happens When You Run It

1. **Models load** — YOLO11s (person detection) + MediaPipe FaceLandmarker load once
2. **Preview window opens** — shows the video at real speed with AI overlays
3. **AI runs in background** — detects all students, assigns stable seat IDs
4. **Per-student overlays** — each student gets a coloured box with attention score, activity label, and metrics
5. **When done (or Q pressed)** — saves `outputs/annotated.mp4` and `outputs/report.txt`

## Controls During Playback

| Key | What it does |
|-----|-------------|
| `D` | Toggle between **Detail mode** and **Compact mode** (see below) |
| `SPACE` | Pause / resume the video |
| `+` or `=` | Speed up playback (up to 4×). AI still runs at same rate. |
| `-` or `_` | Slow down playback (minimum 0.25×) |
| `Q` or `ESC` | Stop and save report immediately |

## Overlay Modes

### Detail Mode (default, press D to toggle off)

Each student shows a full info panel:

```
┌─────────────────────┐
│ STUDY          84%  │  ← activity + attention score
│ [████████░░░░░░░░]  │  ← attention bar
│ Avg 81%             │  ← rolling average
│ [████████░░]        │
│ Emo: neutral        │  ← detected emotion
│ Y:+5 P:-12          │  ← head yaw and pitch (degrees)
│ Eye:0.87            │  ← eye openness (0=closed, 1=open)
│ [███████████░░░░]   │
│ HP:0.91 Mo:0.88     │  ← head pose factor, motion factor
│ momentarily dist.   │  ← reconciliation note (if any)
└─────────────────────┘
```

Plus badges above the box showing Seat ID and grid cell.

### Compact Mode (press D once)

Minimal overlay:
```
S3 STUDY 84%          ← badge: seat ID, activity, attention %
[████████████░░░░░]   ← attention bar below the bounding box
```

Use compact mode when the classroom is crowded and panels overlap.

## Tuning Options

Open `analyze.py` in a text editor and change these values at the top:

```python
MAX_SEATS    = 15     # set to actual number of students in the room
                      # higher = allows more seat IDs to be tracked

YOLO_CONF    = 0.30   # person detection confidence threshold
                      # range: 0.15 (more detections) to 0.50 (fewer, cleaner)
                      # increase if you see ghost boxes on walls/furniture

IOU_SUPPRESS = 0.45   # overlap suppression threshold
                      # increase if two students are being merged into one box
                      # decrease if one student is splitting into two boxes

DISPLAY_W    = 1280   # preview window width in pixels
                      # change to match your monitor size

AI_EVERY     = 2      # run full AI every N frames
                      # 1 = every frame (slow but most accurate)
                      # 2 = every 2nd frame (good balance, default)
                      # 4 = every 4th frame (faster, slight lag on overlays)
```

## Troubleshooting

**"ERROR: Video not found"**
Make sure `videos/real_classroom.mp4` exists. Or pass your video as an argument:
```bash
python analyze.py "C:\path\to\your\video.mp4"
```

**"No module named 'core'"**
You need to be in the `classrom video of wit/` folder, and the parent `classroom/backend/` folder must exist with the core modules. Run from terminal:
```bash
cd "C:\Users\rajea\Documents\classroom\classrom video of wit"
python analyze.py
```

**"ModuleNotFoundError: No module named 'ultralytics'"**
Install dependencies first:
```bash
cd "C:\Users\rajea\Documents\classroom"
pip install -r backend/requirements.txt
```

**No students detected / all boxes disappear**
- Lower `YOLO_CONF` to `0.20` in `analyze.py`
- Make sure the video has good lighting
- Check that `MAX_SEATS` is at least as large as the number of students

**Too many false boxes (walls, furniture detected)**
- Raise `YOLO_CONF` to `0.40` in `analyze.py`
- Raise `IOU_SUPPRESS` to `0.55`

**Overlays are misaligned (boxes on wrong students)**
This happens in the first few seconds while the stabilizer is locking seat positions. It corrects itself after ~5 seconds.

## How the AI Works (brief)

1. **YOLO11s** detects every person in the frame and assigns a tracking ID
2. **SeatStabilizer** maps tracking IDs to stable seat numbers (S1, S2, ...) that never change during the session
3. **MediaPipe FaceLandmarker** detects 468 facial landmarks on each person's head crop
4. **Head pose estimation** (solvePnP) extracts yaw, pitch, and roll angles
5. **Attention score** is computed from head pose + eye openness + motion stability
6. **Activity classification** applies priority rules (phone → drowsy → talking → distracted → studying → attentive)
7. **Reconciliation** corrects the final label against the session average (e.g. a student with 82% avg can't really be "distracted")
8. **Bbox interpolation** smooths overlay positions between AI frames so boxes glide instead of jump
